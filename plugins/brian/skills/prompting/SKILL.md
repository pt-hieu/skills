# Prompting

## When to Use
- Creating a new LLM agent (prose-first output by default; structured schemas only for non-LLM consumers)
- Improving an existing agent's prompt quality
- Diagnosing why an agent produces vague, overconfident, or hallucinated outputs
- Deciding when an output should be free prose vs. a structured schema (consumer type decides)
- Understanding research-backed best practices for reliable LLM prompting
