# Interaction Patterns

## No Hidden Interactions

Every interactive element must look interactive. No discoverable-only-by-accident UX.

- Clickable → cursor change + a visual cue (underline, button style, hover state).
- Expandable → a visible toggle or chevron.
- Data users compare across rows belongs in visible columns, not tooltips.
- Tooltips are for definitions only — never for primary data values.

## Critical Operations

Destructive or irreversible actions (delete, exit position, cancel order) must require explicit confirmation before they execute.

## Progressive Disclosure

Dense surfaces deliver value at a glance. Long supplementary text — interpretation, secondary analysis — is collapsed by default and revealed via a toggle. Never wall the primary content with paragraphs.

## Expand / Collapse

- The chevron sits to the LEFT of the title; it rotates 90° on open.
- Expanded content is a seamless extension of its parent — same background, thin divider, indented past the chevron.
- The title row IS the trigger. No separate "Show / Hide" text.

## Iconography

Use one icon family across the entire product. Mixed icon sets read as inconsistency.

## Metric Definitions

When a metric needs explanation, attach a small info icon next to the label with a tooltip definition. Use this for metric meaning only — never for the metric value itself.
