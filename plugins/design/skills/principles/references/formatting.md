# Formatting

## Text Casing

- **No ALL CAPS in copy.** Reserved for short card/section titles only — never for body, labels, or navigation.
- **Labels and navigation** — sentence case.
- **Chips and badges** — Title Case.

## Dates

Display dates as `DD MMM YYYY` (e.g., "02 Feb 2026"). Consistent date format across the entire product — users should never have to re-parse what they're reading.

## Numbers

- Currency, percent, and compact-number formatting must be consistent everywhere.
- Null / missing values render as a single placeholder character or an empty state — never as "null", "N/A", or a blank cell.
