# Banned Patterns

- **No colored accent stripes on cards.** Differentiate cards via background tint, badge color, or icon color — never via a left/top color bar. Stripes fragment the visual grid.
- **Stick to a defined type scale.** Never invent one-off font sizes. If the size you want isn't in the scale, you're using the wrong element, not the wrong size.
- **Text must read at full opacity.** Never rely on transparency to make text "softer" — use a darker/lighter color from the palette instead. Faded text is unreadable text.
