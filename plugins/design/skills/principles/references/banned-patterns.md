# Banned Patterns

- **No colored accent stripes on cards.** Differentiate cards via background tint, badge color, or icon color — never via a left/top color bar. Stripes fragment the visual grid.
- **Stick to a defined type scale.** Never invent one-off font sizes. If the size you want isn't in the scale, you're using the wrong element, not the wrong size.
- **Live text reads at full opacity.** Never rely on transparency to make live text "softer" — use a darker/lighter color from the palette instead. Faded text is unreadable text. The one sanctioned use of reduced opacity is whole-container dimming of stale/superseded items (design-principles 6–7): dim the container as a unit, never individual text runs, and keep the dimmed content above readable contrast.
